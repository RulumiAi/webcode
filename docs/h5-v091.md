# H5 refinements v0.9.1

- Move mobile language choice to a native selector over a compact globe in the fixed application header. It shares the existing locale preference callback. Remove the separate language row from the discovery header.
- Reduce search to 34px, category gaps to 15px, category heights to 36px, and inline tag/dropdown controls to matching 26px heights.
- Preserve SVG geometry with non-shrinking icons. Explicitly override the generic 44px mobile minimum on circular favorites and small icon controls. Character/story favorites are 28×28px.
- Mobile primary navigation derives its grid column count from the actual item count (four today), with equal columns and 20px square icons.
- Rework mobile profile header, avatar, settings and preferences alignment. Add entire-card wallet and VIP entry buttons with gold and violet fills. Keep collection/history counters in their own two-column row; desktop presentation is unchanged.
- Comic and video detail readers are viewport-filling overlays above application chrome, including locally published comics. Respect safe areas, natural image/video proportions, chapter switches, unlock confirmation and close controls. This is an immersive in-app layout, not automatic browser-native fullscreen.
- The desktop H5 preview wrapper now offers 320/390/430/768px width selection.

Browser QA: 28×28 favorite geometry, equal bottom columns at 320px, square profile SVGs, no horizontal overflow at 320/390/430px, Korean locale selection through header, comic/video dialogs at x=0/y=0 with viewport height, free-to-paid chapter transitions, wallet/VIP navigation and native tag dropdown behavior.

Deployment update: changed source files and newly built JS/CSS/HTML can be applied over the v0.9.0 release; the existing image/video asset tree remains required. These layout changes do not connect a real backend/model/payment service.
